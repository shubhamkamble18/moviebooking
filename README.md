# 🎬 CineBook – Movie Ticket Booking Website

CineBook is a modern and responsive **Movie Ticket Booking Website** built using **React.js**. It allows users to explore movies, view movie details, check available show information, and go through a simple ticket-booking interface.

The project focuses on creating a clean, user-friendly movie booking experience with a responsive design for desktop and mobile devices.

## 🚀 Live Demo

🔗 **Live Website:** https://shubhamkamble-portfolio.netlify.app/

## 📌 Features

* 🎬 Browse available movies
* 🔍 Search and explore movies
* 🎭 Filter movies by genre and language
* 📄 View detailed movie information

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-username/cinebook.git
```

### 2. Navigate to the project folder

```bash
cd cinebook
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will run locally, usually at:

```text
http://localhost:5173
```

## 🎯 How It Works

1. Users open the CineBook homepage.
2. Users browse the available movies.
3. They can filter movies by genre or language.
4. Users select a movie to view its details.
5. They select a showtime and proceed to booking.
6. A simulated payment process is displayed.
7. After completing the process, a booking confirmation is shown.

> **Note:** This project uses a simulated payment/booking flow for demonstration purposes. It does not process real payments.
